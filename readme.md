# 🚶 Passenger Counter App

A simple and interactive **Passenger Counter App** built with **HTML**, **CSS**, and **JavaScript**. The application allows users to count passengers, save previous counts, and reset the counter after each save.

## 📖 About

The Passenger Counter App is a beginner-friendly JavaScript project that helps users count passengers entering a location. Every click on the **Increment** button increases the count, while the **Save** button stores the current count and resets the counter for the next entry.

This project demonstrates the basics of JavaScript, including DOM manipulation, event listeners, variables, and updating webpage content dynamically.

---

## ✨ Features

- ➕ Increment passenger count
- 💾 Save previous counts
- 🔄 Automatically reset the counter after saving
- 📋 Display saved count history

## ⚙️ How It Works

1. The counter starts at **0**.
2. Click **Increment** to increase the passenger count.
3. Click **Save** to:
   - Save the current count.
   - Append it to the history.
   - Reset the counter to **0**.
4. Continue counting new passengers.
